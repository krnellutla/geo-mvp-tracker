**Krishna · set 2 Oct 2026 · horizon 2 Apr 2027** · a direction, not a product

**By 2 April 2027, I can take any problem I have observed in a real person from a written spec to a verified, running LLM MVP in under one week, and I can explain every line of it.**

"Mastering" here means three things I can show, not claim:

1. **Spec before code.** Every build starts with an observation, a numeric hypothesis, golden pairs and a verifier.
2. **Verifier-first.** I can say, with arithmetic, whether an MVP worked, and I stop the ones that did not.
3. **Recall.** I can rebuild the core loop (input, process, output) without a chatbot.
